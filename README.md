# QZPAY

Операторский кабинет: дашборд, заявки, реквизиты, баланс, выплаты, API и настройки.

## Текущий этап
Функциональная демонстрационная версия. Данные хранятся в localStorage браузера. Авторизация, общая база, интеграция бота и реальные переводы ещё не подключены. Не использовать для реальных денег и персональных данных. Данные между вкладками и устройствами не синхронизируются.

Реализованы график, финансовые показатели, тестовые заявки, фильтры и CSV, подтверждение, отказ, истечение 25 минут, позднее подтверждение, включение реквизитов, тестовые пополнения и учёт выплат.

Расчёт: KZT × 0.90 ÷ курс. При 20000 ₸ и 485 = 37.113402 USDT. Учёт — 6 знаков, интерфейс — 2 знака. Курс сохраняется в заявке.

## Запуск
Node.js 22+. Внешних зависимостей нет.

    npm test
    npm run build
    npm run dev

Открыть http://localhost:4173. Vercel: Framework Other, build `npm run build`, output `dist`.

## Следующий этап
API.md — проект контракта, не рабочая документация. Нужны сервер, БД, вход и роли, ключи партнёров, интеграция бота №1, приём чеков, проверка пополнений и аудит. XLSX, редактирование реквизитов и изменение фактической суммы также пока не реализованы. Старый бот №2 не изменялся.

Реальные реквизиты со скриншотов не включены. Секреты не коммитить.
